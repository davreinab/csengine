Design System del prototipo

Fuente de verdad: design-tokens.json → styles/tokens.css (generado con node tools/tokens-to-css.mjs). Un único archivo de estilos: styles/components.css. Validación: node tools/lint-tokens.mjs.

Arquitectura de variables (3 niveles)

Regla: el CSS solo aplica estilos con variables. Los colores SIEMPRE via nivel semántico o de componente — las primitivas de color no se usan directamente en reglas. Nivel 1 primitivas (valores crudos: escalas de color, tipos, tamaños, espacios) → Nivel 2 semánticas (roles: --color-page, --color-text, --color-accent…) → Nivel 3 componente (--btn-primary-bg, --card-radius, --mlogo-w…).
